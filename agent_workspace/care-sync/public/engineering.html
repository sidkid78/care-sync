Executive System Architecture

The Care-Sync architecture is strategically engineered as a hybrid Next.js and Supabase ecosystem. This stack was selected to reconcile the high-velocity requirements of a modern caregiving application with the uncompromising security posture required for HIPAA-aligned data management.

CORE STACK VISUALIZATION

  • Frontend Next.js (App Router)
  • BaaS Supabase (PostgreSQL)
  • Async Compute AWS Lambda / SQS
  • Security AWS KMS

Secure Data Modeling

We treat the "Family" as the fundamental tenant, requiring absolute isolation to prevent cross-tenant data leakage via Row Level Security (RLS).

Profiles Schema

Extends auth.users. Includes role (senior, caregiver), subscription_status, and stripe_customer_id.

Family Tenant

Junction table constraints define the link between users and families using unique invite_codes.

RLS Defense

The database engine rejects unauthorized queries based on family_id. No reliance on client-side logic.

Agentic AI Integration

Doctor Digest

Converts clinical audio to structured intelligence. Uses Google Gemini 2.5 Flash for multimodal analysis and summarization. Raw audio is purged post-process.

Med-Cabinet Scanner

Multi-stage pipeline: OCR -> Drug Identification (RxNorm) -> Conflict Checking against DB profile.

Quantitative Vibe Check

Google Cloud Natural Language API transforms caregiver notes into sentiment trends.

THE VAULT

ZERO-KNOWLEDGE ARCHITECTURE

Even if a malicious actor gains full access to Storage and PostgreSQL, they cannot decrypt the documents. Key derivation happens exclusively on the client.

1. Key Derivation (PBKDF2)
2. Blob Encryption (AES-256 GCM)
3. Integrity Check (SHA256)

Real-time Coordination

"Who's On Duty?" Scheduling System backed by PostgreSQL RLS. Complex logic like Shift Swapping is handled by Edge Functions to ensure atomicity.

Real-time Family Feed

Utilizes supabase.channel() for Postgres CDC. Live "heartbeat" of the care environment without manual refreshing.

Feature Gating (Freemium)

  • > Free Tier: Manual entries, Basic Chat
  • > Premium ($9.99/mo): Doctor Digest, Med Scanner
  • > Validation: Worker Services perform final check.

Accessibility (WCAG AAA)

Global AccessibilityContext injects data-theme for high-contrast. "Passive Mode" for seniors simplifies dashboard to a clock and visitor photo.
